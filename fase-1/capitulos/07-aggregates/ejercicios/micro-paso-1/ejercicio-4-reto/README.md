# Ejercicio 4 (opcional) — Reto: dos asignaciones → versión 2 ✍️

> Cap. 7 · micro-paso 1 · refuerzo. Lo resuelves tú.

**Problema:**
1. Haz un `Producto` con un lote grande. Asigna **dos** líneas seguidas y comprueba que `numeroVersion` queda en 2.

**Tu turno:**
- Versión mala (sube la versión una sola vez, o no la sube) en [`solucion-mala/main.php`](solucion-mala/main.php).
- Versión buena (sube `numeroVersion` en cada asignación → 2) en [`solucion-buena/main.php`](solucion-buena/main.php).

```bash
php solucion-mala/main.php
php solucion-buena/main.php
```
