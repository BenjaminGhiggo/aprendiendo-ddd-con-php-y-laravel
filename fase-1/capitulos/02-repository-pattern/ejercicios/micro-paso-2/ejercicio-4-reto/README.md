# Ejercicio 4 (opcional) — Reto: un lote con dos asignaciones ✍️

> Cap. 2 · micro-paso 2 · refuerzo. Lo resuelves tú.

**Problema:**
1. Modela un `Lote(comprado=20)`, asígnale dos líneas distintas (2 y 3) y muestra `disponible()` (debe dar 15).
2. Vuelve a asignar una de ellas (misma clave) y comprueba que **no** vuelve a descontar.

**Tu turno:**
- Versión mala (disponible como dato que actualizas a mano) en [`solucion-mala/main.php`](solucion-mala/main.php).
- Versión buena (asignaciones por clave + `disponible()` calculado) en [`solucion-buena/main.php`](solucion-buena/main.php).

```bash
php solucion-mala/main.php
php solucion-buena/main.php
```
