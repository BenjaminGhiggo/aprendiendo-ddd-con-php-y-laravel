1. Hay dos lotes del mismo sku. Al bajar el primero, la línea que sobra debe reasignarse al segundo (no quedar `SinStock`).

**Tu turno:**
- Versión mala (un solo lote: la línea queda sin sitio) en [`solucion-mala/main.php`](solucion-mala/main.php).

```bash
php solucion-mala/main.php
```
